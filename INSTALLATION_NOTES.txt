橙意翻译助手 0.3.0 — Windows 10/11 x64

此安装版已内置 Python 运行环境、PDFMathTranslate 2.9.0、BabelDOC 0.6.4、字体、版面识别模型和必需运行库。无需另装 Python，不依赖原开发电脑的 C 盘环境。

安装完成后，从桌面或开始菜单打开橙意翻译助手。程序会自动启动本机服务并打开浏览器页面；只监听随机的本机端口，不向局域网开放。重复启动会打开已有服务。浏览器关闭后，翻译队列继续运行。

首次使用：
1. 在百度翻译开放平台注册开发者并开通相应服务。默认模式使用百度大模型文本翻译 API Key，按学术风格翻译；高级模式可选学术论文领域 API（domain=academic），需另一类 APPID 和密钥。
2. 在本软件设置中填写对应凭据。凭据用当前 Windows 用户的 DPAPI 加密保存在本机，不会写入安装包或翻译日志。更换电脑需要重新输入密钥。
3. 上传含可复制英文文字的 PDF，核对自动提取的保留英文名称，按需补充作者名、期刊名、模型方法名。
4. 点击开始翻译。默认保留参考文献整段英文，完成后下载无额外水印的中文版和中英并排版。

当前版本通过 HTTPS 直接调用百度官方翻译接口，读取并验证全部返回结果。免费额度、额度周期及超额费用以你的百度控制台当时显示为准。网页会员不自动等于 API 权限。没有凭据时仍可打开软件、上传 PDF 和核对术语。测试连接会发送一次短句请求，可能计入额度。

0.3.0 修复旧版只读取首条翻译结果造成的截断，隔离旧版大模型翻译缓存，并修复 Windows 进度文件临时占用导致任务中断的问题。遇到翻译校验失败可调整原任务术语后重试，完整的新缓存会继续复用。

术语保护在本机先遮罩、翻译后校验并恢复原文；术语清单可人工增删。自动识别人名和期刊不是百分之百准确，重要稿件请核对清单。扫描件应先进行OCR。翻译速度受页数、图表、网络和API账户QPS配额影响。

个人配置、历史和缓存位于：%LocalAppData%\PaperTranslator
服务日志：该目录的 server.log；启动错误：launcher.log；各任务另有 translation.log。
卸载程序不会自动删除个人翻译数据。

第三方开源许可随安装目录分发。PDFMathTranslate与BabelDOC的许可和对应源码位于 engine/ 和 THIRD_PARTY_LICENSES/，本软件对引擎的兼容修改及新增源码也随包提供。

百度 API Key 模式已通过原21个失败段的重放及26页论文全篇翻译、双版本导出验证；学术论文领域 APPID 模式的签名与错误处理使用离线模拟接口验证。安装包不包含开发者或用户的个人 API 凭据。
